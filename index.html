🛠️ Accesibilidad y ajustes

Si lo activas, lo que Jesús diga con sus frases (solo texto, nunca fotos) se envía a la API de Claude (Anthropic) para responder de forma más viva y hacerle preguntas sencillas que le animen a hablar él mismo. Tiene coste por uso, necesita internet, y la clave se guarda solo en este móvil — cualquiera con acceso al dispositivo podría verla. Si no lo activas, el amigo sigue funcionando con respuestas fijas, sin coste ni conexión.
